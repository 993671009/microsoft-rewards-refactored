## 📋 功能概览

每天在后台自动完成 Microsoft Rewards 任务获取积分奖励：

| 功能 | 自动化内容 
|---|---|
| ✅ 每日签到 | App 端 + PC 端签到 |
| ✅ 新闻阅读 | 查询进度、执行阅读、二次确认 |
| ✅ 活动卡片 | 发现并提交活动、过滤已完成项目 |
| ✅ PC 搜索 | 自动生成或获取搜索词并上报进度 |
| ✅ 连签检测 | 检查搜索、活动、应用及视觉搜索连签状态 |
| ✅ 每日活动 | 在 Rewards 页面查找并点击未完成的每日活动 |
| ✅ 待领取积分 | 检查 Rewards 页面并点击领取按钮 |
| ✅ 积分通知 | 浏览器通知；企业微信、钉钉、飞书、PushMe、Bark 可选推送 |
| 🛡️ 地区保护 | 根据 Bing 地区信息检测，非大陆 IP 自动停止任务 |

## ⚙️ 配置说明

### 基础配置

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 持续检测 | 全部完成后是否继续运行 | 开启 |
| 锁定国区 | 非大陆 IP 自动停止 | 开启 |
| 搜索间隔 | 搜索间隔时间（秒） | 30±15秒 |
| 搜索词接口 | 搜索词来源 | offline（随机） |
| 授权码链接 | 粘贴登录跳转后的完整 URL | 空 |

### 任务开关

| 任务 | 说明 | 默认 |
|---|---|---|
| 每日签入 | PC+App 签到 | 开启 |
| 新闻阅读 | 阅读文章获取积分 | 开启 |
| 活动卡片 | 领取各类活动奖励 | 开启 |
| Quiz 自动答题 | 处理 Quiz 测验卡片 | 开启 |
| PC 搜索 | 完成搜索任务 | 开启 |

### 通知渠道

支持以下通知渠道（可选配置）：

- **企业微信**：群机器人 Webhook
- **钉钉**：群机器人 Access Token（关键词需包含 `#`）
- **飞书**：群机器人 Webhook（关键词需包含 `#`）
- **PushMe**：`push.i-i.me` 推送 key
- **Bark**：`bark.day.app` 推送 key

## ⚠️ 防封号机制

以下措施用于控制运行频率，不保证账号不会被限制：

1. **随机延迟**：部分任务间及点击前后等待 3-8 秒，具体间隔因操作而异。
2. **搜索间隔**：默认 30±15 秒。
3. **随机启动**：自动任务启动前等待 5-95 秒。
4. **IP 检测**：开启锁定国区后，非大陆 IP 自动停止。
5. **搜索限制检测**：连续 3 次检测到未满配额且进度不变时中断搜索。

❓ 常见问题

### Q: 为什么会自动打开 Dashboard？

A: 后台运行每日活动或领取积分时会打开 [Microsoft Rewards Dashboard](https://rewards.bing.com/dashboard)。一轮运行可能打开两次，这是脚本当前逻辑造成的，但不会无限循环。

### Q: 授权码在哪里获取？

A: 脚本会自动打开授权页面，登录后复制地址栏 URL，粘贴到脚本设置的「授权码链接」中。

### Q: 为什么搜索没有积分？

A: 可能是搜索受限，请检查是否开启了「锁定国区」功能，确保使用大陆 IP。

### Q: 如何配置通知？

A: 在脚本管理器中打开脚本设置，找到「通知接口配置」菜单，按提示配置即可。

### Q: 支持哪些浏览器？

A: 支持 Chrome、Edge、Firefox 等主流浏览器，需安装 ScriptCat 或 Tampermonkey 扩展。
